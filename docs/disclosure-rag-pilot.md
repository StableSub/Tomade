- SQLite 메타데이터/FTS5 BM25, OpenAI text-embedding-3-small, NumPy 코사인 검색, RRF, 부모 문맥 보강.
- 회사·공개일·선택 보고서 필터와 선택 목차 우선 검색. 같은 저장소 재사용.
- 조사 회사·기준일을 고정하고 호출 3회로 제한하는 LangChain Tool factory. **기존 Worker/Chat 그래프에는 아직 등록하지 않음.**

## 검색 전에 정한 평가 기준

원문을 먼저 읽고 질문 3개와 기대 구문·블록 ID를 `evals/datasets/disclosure_rag_samsung.json`에 저장했다. 검색 전에 각 기대 구문이 해당 블록에 있는지 확인했다. **상위 5개 결과의 자식 텍스트에 지정 블록 ID와 구문이 함께 있으면 통과**한다. 평가 이후 다른 근거를 정답으로 추가하지 않았다.

설정: 회사 00126380, 기준일 2026-09-17, 공시 20260310002820, 목차 힌트 없음, BM25/벡터 각 15개, RRF 상수 60, 최종 5개. 질의 재작성·추가 검색·LLM 답변 생성 없음.

| 질문 | 고정 위치 검사 | 반환 결과를 읽은 관찰 |
| --- | --- | --- |
| DS 부문은 어떤 사업들로 구성되어 있나요? | 실패 | 기대 위치는 본문 271행. 대신 3위 첨부 주석에서 DS가 메모리·Foundry·System LSI로 구성된다는 설명을 찾음. 2위의 주변 문맥에도 관련 제품 설명이 있음 |
| 해외 지역별 자금은 어떤 방식으로 운용하여 유동성 위험에 대응하나요? | 실패 | 기대 위치는 본문 6061행. 대신 3위 첨부 주석과 5위 본문에서 권역별 Cash Pooling·자금 공유 설명을 찾음 |
| 연결 기준 단기차입금의 차입처와 연이자율 범위는? | **통과 · 2위** | 본문 21340행의 지정 차입금 표에서 차입처와 연이자율 행을 확인 |

검색 소요 시간은 순서대로 약 0.857초 / 0.251초 / 0.266초다. 준비된 색인에서 1회씩 측정한 값이며 평균·p95 성능이 아니다.

**해석:** 지정한 근거 위치의 회수율은 1/3이다. 두 실패 질문에도 의미상 관련된 대체 원문이 검색돼 “아무 근거도 못 찾음”과는 다르다. 그러나 대체 근거를 인정하는 독립 평가나 실제 Agent 답변 품질 평가는 하지 않았으므로 3/3 성공으로 재분류하지 않는다.

### 관측된 문제와 원인 가설 — 수정하지 않음

- 회사 사업 질문에서 자회사 목록 표가 1위로 올라왔다. 주변 문단을 검색 텍스트에도 포함하는 방식이 짧은 표·제목의 순위를 높일 수 있다. 반환 결과로 확인된 현상과 코드에 근거한 가설이며 원인별 실험은 하지 않았다.
- 유동성 질문에서 단위만 있는 표와 짧은 소제목도 상위에 포함됐다. 같은 부모의 겹치는 문맥을 충분히 줄이지 못한다.
- 단기차입금 질문에서 장기차입금 표가 1위였다. 지정 단기차입금 표는 2위였다.
- 본문·첨부에 반복된 설명이 있다. 현재 중복 제거는 같은 블록 ID에 한정하므로 문서 간 의미 중복은 남는다.
- 평가 정답이 단일 원문 위치이므로 동등한 다른 근거를 실패로 계산하는 한계가 있다. 이번 실행에서는 기준을 변경하지 않았다.

## 코드·Mock 검증

`tests.test_disclosure_rag` **6개 통과**. 원문 구조·bare ampersand, 표 헤더·병합 셀, ZIP 경로·선언 거부, 저장 재사용, 하이브리드 결과, 회사·미래 공시 제외, 정정 미확인 거부, Tool 예산, 페이지·API 오류 구분을 확인했다.

실제 색인에서도 다른 회사와 공개 전날(2026-03-09) 검색은 빈 결과로 통과했다. Python compileall과 git diff --check를 확인했다. 전체 테스트·프론트엔드 빌드·실제 Agent 호출은 수행하지 않았다.

## 남은 범위

- 1개 공시 파일럿이다. 신규 공시 자동 수집, 정정 관계 자동 연결, 두 기간 숫자 정규화·계산, Worker 통합은 미구현이다.
- 정정·철회 표시가 있는 보고서는 잘못 선택하지 않도록 현재 준비 단계에서 거부한다.
- 검색어는 어절+한글 2글자 부분어를 문서/질문에 동일 적용한다. 형태소 분석기·역할별 프로필·자동 재작성·리랭커는 추가하지 않았다.
- 표의 헤더·단위는 텍스트 문맥으로 보존한다. 재무 기간·연결/별도·통화를 독립적인 typed 필드로 정규화한 것은 아니다.
- 원문 준비는 단일 writer로 사용한다. 동시 수집·대형 코퍼스·다른 회사의 문서 형식까지 보장하지 않는다.
- 줄 위치와 원문 구문은 추적되지만 모든 원문 내용이 손실 없이 추출됐다는 전수 검증은 하지 않았다.

## 실행

프로젝트 가상환경에 `pip install -e .`로 의존성을 설치한 뒤 저장소 루트에서 실행한다. `.env`에는 `DART_OPENAPI_KEY`와 `OPENAI_API_KEY`가 필요하다.

```bash
PYTHONPATH=src .venv/bin/python -m stock_agent.rag --env-file .env prepare \
  --corp-code 00126380 --start 2026-01-01 --as-of 2026-09-17 --receipt 20260310002820

PYTHONPATH=src .venv/bin/python -m stock_agent.rag --env-file .env search \
  --corp-code 00126380 --as-of 2026-09-17 --receipt 20260310002820 \
  --query '연결 기준 단기차입금의 차입처와 연이자율 범위를 알려주세요.'

PYTHONPATH=src .venv/bin/python -m unittest tests.test_disclosure_rag -v

PYTHONPATH=src .venv/bin/python evals/scripts/check_disclosure_rag.py --env-file .env
```

이번 작업에서는 원래 프로젝트의 `.venv/bin/python`과 `.env`를 절대경로로 지정하고 feature worktree에서 실행했다. 마지막 평가 명령은 알려진 2개 실패 때문에 종료 코드 1을 반환한다. 결과는 `evals/results/disclosure-rag-samsung.json`에 보존된다.
