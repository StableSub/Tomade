# Tomade 도트 사무실 배경

[소품 v4](office-objects-v4/README.md)는 승인된 [직원 책상 v3](office-objects-v3/README.md)와 마당의 질감에 맞춰 나머지 가구·소품·구조물 26종을 재제작한 현재 에셋입니다. 가구 9종·세부 소품 9종·구조물 8종을 아틀라스 3장과 `frames.json`으로 관리하며, 세 직원 책상은 v3 원본을 공유합니다. `office-room.ts`가 독립 배치하고 `pixel-style.ts`가 기본 직원 캐릭터의 픽셀 배율(0.54게임단위/픽셀)과 실루엣 안쪽 2픽셀의 짙은 윤곽을 적용합니다. 모서리와 다리 사이 경계까지 이어지는 윤곽을 우선하며 내부 색상은 원본 RGB를 보존합니다. [에셋 뷰어](office-objects-v1/index.html)도 같은 변환을 사용합니다. v1·[v2](office-objects-v2/README.md) 원본은 제작 이력으로 보존합니다.

[배경 오브젝트 뷰어](office-environment-v1/index.html)는 바닥·벽·칸막이·목재 테두리·계단 8종의 레이어와 반복 타일을 보여줍니다. 현재 구조물은 v4 아틀라스를 사용하며 가구와 합쳐 실내 54개 오브젝트를 구성합니다. 구조물에도 같은 도트 격자·원본 색상 보존을 적용하되 평평한 벽면에는 윤곽을 더하지 않습니다. 바닥의 1게임단위 격자는 유지하고, 나무 바닥은 기존 정수 좌표 SVG 타일을 공통 원점으로 반복해 이음선을 맞춥니다. [배경 v1](office-environment-v1/README.md)·[v2 벽·계단](office-environment-v2/README.md)은 제작 이력입니다.

`research-office.png`는 사용자가 승인한 두 방 구조의 16:10 디자인 참고 이미지이며 현재 앱에서 로딩하지 않습니다. 패트와 매트 집 분위기의 목재 가구·체크 커튼·녹색 난로, 밝은 나무 짜임 바닥과 연녹색·아이보리 체크 타일의 방 구분, 작은 토마토 소품을 독립 에셋 배치에 반영했습니다. [기준 배경 프롬프트](research-office.prompt.md)를 함께 보존했습니다.

앞쪽 벽지 두 면은 제거하고 목재 테두리·기둥만 남겼습니다. 가운데 칸막이는 기둥과 폭을 맞추고, 통로와 입구 바닥은 기둥 안쪽에서 끊습니다. 계단 윗단은 입구 바닥에 겹쳐 연결하고 아래에 접지 그림자를 배치합니다.

[마당 v2](office-courtyard-v2/README.md)는 승인된 시안에 맞춰 생성한 9종 아틀라스입니다. 나무·꽃 관목·화분·벤치·화단·징검돌·돌·풀·들꽃을 배치하며, 흰 테라스를 제거해 잔디가 집까지 이어집니다. 실내와 마당을 합쳐 42개 에셋 ID를 101개 오브젝트로 배치합니다. 마당도 기존 0.54단위 도트 격자와 원본 RGB 보존을 사용하되 작은 풀꽃은 원본의 가는 경계를 유지합니다. 소품 뷰어에서 개별 비교할 수 있습니다.

세 Worker 모니터에는 비즈니스의 실적 막대 차트, 매크로/섹터의 시장 추세선, 이벤트/카탈리스트의 일정·뉴스 목록을 표시합니다. 역할을 구분하는 독립 모니터 소품이며 실시간 데이터나 실제 조사 결과를 표시하지 않습니다. 부장 모니터는 뒷면을 유지하고 책상 중앙 쪽으로 옮겨 받침대가 상판 앞선 안에 놓이도록 했습니다.

접지 그림자는 원본 PNG에 합치지 않고 `office-room.ts`가 별도 요소로 배치합니다. 가구는 바닥 위에 옅은 면과 다리 밑의 진한 면을, 모니터·컵·화분은 받침면 위에 작은 그림자를 둡니다. `styles.css`에서 캐릭터와 같은 갈색·계단형 경계를 사용하고 클릭을 가로채지 않습니다. 왼쪽 아래 컵은 바닥점이 장식장 상판 안으로 들어오도록 배치했습니다.

`office-characters.png`는 승인한 캐릭터 디자인을 기준으로 built-in `image_gen`으로 만든 4×4 시트입니다. 행은 부장 페더스 맥그로·비즈니스 패트·매크로/섹터 매트·이벤트/카탈리스트 게왹이, 열은 정면·뒷모습·오른쪽·착석입니다. 부장은 정면, 직원은 뒷모습으로 앉습니다. 시트의 자홍색 배경은 `office-scene.ts`에서 로딩 시 한 번 투명 처리합니다. 원본 그림의 비율을 유지해 128×160 Canvas에 표시하며 부장 초상화도 같은 시트에서 가져옵니다. 가구와 캐릭터가 `OFFICE_SEATS` 좌표를 공유하며, 독립 의자·책상을 깊이 순서에 맞춰 겹쳐 착석을 표현합니다.

캐릭터 생성·편집 프롬프트는 [office-characters.prompt.md](office-characters.prompt.md)에 보존했습니다.

`office-walk-front.png`·`office-walk-back.png`·`office-walk-right.png`는 같은 네 캐릭터의 방향별 4프레임 걷기 시트입니다. 기존 이동·착석·보고 로직을 사용하며 실제 이동 거리에 맞춰 짧은 걸음을 반복하고, 정지하면 기본 시트로 돌아갑니다. 왼쪽은 오른쪽 그림을 반전합니다. 가로로 긴 방에서도 상하·좌우의 이동 속도와 걸음 간격이 같도록 거리 계산에 방 비율을 반영합니다. 생성 및 보정에 사용한 built-in `image_gen` 프롬프트는 [office-walk.prompt.md](office-walk.prompt.md)에 보존했습니다.

이전의 장식이 많은 배경은 Git 이력에 보존되어 있습니다.

[집 외곽 v1](office-shell-v1/README.md)은 승인된 정돈된 집 시안을 반영합니다. v4의 목재·기둥·계단을 대체하며, 캡 장식을 없애고 돌 기단·문턱·토마토색 처마를 추가합니다. 소품과 인물은 기존 에셋을 유지합니다.

- `office-kirby-v2/walking-atlas.png`: 서류를 든 작은 원형 커비. 정면·후면·오른쪽 각 4개의 걷기 프레임, 청록색 키 배경. 기존 캐릭터와 동일한 픽셀 배율로 표시하며 포트폴리오 진입점으로 사용합니다. 생성 프롬프트와 렌더링 규칙은 같은 폴더의 README.md·prompts.json에 있습니다.

## 2026-09-17 — 풍경과 접지감 개선

하늘·먼 숲은 [원경 WebP](office-landscape-v1/garden-horizon.webp) 한 장으로 표시합니다. [생성 프롬프트와 인코딩 조건](office-landscape-v1/prompt.md)을 보존했습니다. 같은 이미지를 창문의 네 유리 영역에 한 번 합성해 세 창문에서 공유하며, 소품 뷰어도 같은 함수를 사용합니다. 커튼·창틀·외곽 알파는 유지합니다.

전체 맞춤 영역은 800×910, 뒤쪽 여백은 210게임단위입니다. 뒤쪽 나무는 180×176으로 키우고 밑동을 y=-22에 두어 처마와 분리했습니다. 앞쪽 나무는 150×168이며 벤치·관목·돌도 겹치지 않게 재배치했습니다. 기존 97개 오브젝트와 실내 좌석·동선은 유지합니다.

가구·나무의 접지 그림자는 0.54게임단위 격자로 생성한 작은 PNG를 크기별로 재사용합니다. 비율 기반 CSS 다각형을 확대하던 방식은 접지 그림자에 사용하지 않습니다. 나무는 수관 그림자와 밑동 접촉 그림자를 분리했습니다. 원경과 창문 합성은 정적이며 매 프레임 다시 처리하지 않습니다.
