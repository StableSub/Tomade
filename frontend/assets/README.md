# Tomade 도트 사무실 배경

[독립 오브젝트 v1](office-objects-v1/README.md)은 현재 배경을 기준으로 별도 생성한 가구·소품 21종입니다. [에셋 뷰어](office-objects-v1/index.html)에서 개별 확대와 배경 전환으로 확인할 수 있습니다. 아직 실제 사무실 배치에는 연결하지 않았습니다.

[배경 오브젝트 v1](office-environment-v1/README.md)은 바닥·벽·칸막이·목재 테두리·계단 8종입니다. [조립 미리보기](office-environment-v1/index.html)에서 각 레이어와 반복 타일을 확인할 수 있습니다. 이 미리보기 역시 실제 앱의 배경을 교체하지 않습니다.

`research-office.png`는 사용자가 승인한 두 방 구조의 16:10 배경입니다. 패트와 매트 집 분위기의 목재 가구·체크 커튼·녹색 난로를 유지하고, 직원 사무실은 밝은 나무 짜임 바닥, 부장실은 연녹색·아이보리 체크 타일로 구분합니다. 토마토는 로고와 작은 소품에만 남겼습니다. built-in `image_gen`으로 시안 속 캐릭터와 대화하기 표시를 지웠으며, 실제 캐릭터와 대화는 HTML·Canvas로 표시합니다. [최종 배경 프롬프트](research-office.prompt.md)를 함께 보존했습니다.

세 Worker 모니터에는 비즈니스의 실적 막대 차트, 매크로/섹터의 시장 추세선·산업 블록, 이벤트/카탈리스트의 일정·뉴스 목록을 표시합니다. 역할을 구분하는 배경 그래픽이며 실시간 데이터나 실제 조사 결과를 표시하지 않습니다. 부장 모니터는 좌석 방향에 맞춰 뒷면을 유지합니다.

`office-characters.png`는 승인한 캐릭터 디자인을 기준으로 built-in `image_gen`으로 만든 4×4 시트입니다. 행은 부장 페더스 맥그로·비즈니스 패트·매크로/섹터 매트·이벤트/카탈리스트 게왹이, 열은 정면·뒷모습·오른쪽·착석입니다. 부장은 정면, 직원은 뒷모습으로 앉습니다. 시트의 자홍색 배경은 `office-scene.ts`에서 로딩 시 한 번 투명 처리합니다. 원본 그림의 비율을 유지해 128×160 Canvas에 표시하며 부장 초상화도 같은 시트에서 가져옵니다. 착석 시 같은 배경의 가구 부분을 앞에 겹쳐 상체와 의자 등받이가 자연스럽게 보이도록 합니다.

캐릭터 생성·편집 프롬프트는 [office-characters.prompt.md](office-characters.prompt.md)에 보존했습니다.

`office-walk-front.png`·`office-walk-back.png`·`office-walk-right.png`는 같은 네 캐릭터의 방향별 4프레임 걷기 시트입니다. 기존 이동·착석·보고 로직을 사용하며 실제 이동 거리에 맞춰 짧은 걸음을 반복하고, 정지하면 기본 시트로 돌아갑니다. 왼쪽은 오른쪽 그림을 반전합니다. 가로로 긴 방에서도 상하·좌우의 이동 속도와 걸음 간격이 같도록 거리 계산에 방 비율을 반영합니다. 생성 및 보정에 사용한 built-in `image_gen` 프롬프트는 [office-walk.prompt.md](office-walk.prompt.md)에 보존했습니다.

이전의 장식이 많은 배경은 Git 이력에 보존되어 있습니다.
