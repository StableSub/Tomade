# 촘촘한 도트 마당

승인된 두 번째 마당 시안을 기준으로 built-in `image_gen`에서 새 아틀라스를 제작했습니다. [prompts.json](prompts.json)에 최종 프롬프트·기준 시안·생성 원본 경로를 보존합니다. CLI fallback은 사용하지 않았습니다.

`garden-atlas.png`는 나무·꽃 관목·토마토 화분·벤치·토마토 화단과 물뿌리개·징검돌·돌·풀·들꽃의 9종입니다. 원본은 변경하지 않고 `loadSpriteSource`에서 정규화한 프레임 영역을 읽어 자홍색을 제거합니다. 화단의 물뿌리개까지 포함하도록 가운데 프레임을 오른쪽으로 넓혔습니다. 실제 영역은 `office-room.ts`와 소품 뷰어의 `prompts.json`에 기록합니다.

기존 큰 색 덩어리의 v1 SVG를 대체합니다. 현재는 실내 소품과 함께 0.54 게임단위 픽셀 격자와 `preserveColors: true`를 사용해 원본 RGB를 보존합니다. 가구·식물은 실루엣 안쪽 2픽셀 윤곽, 아주 작은 풀·들꽃은 추가 윤곽 없이 원본의 가는 경계를 유지합니다. 흰 테라스를 제거하고 잔디색이 건물 벽까지 바로 이어지게 했습니다.

실내 800×500 좌표는 유지합니다. 위쪽 나무 공간 70단위를 포함해 전체 맞춤 영역은 800×700입니다. 마당 54개 장식은 독립 DOM이며 클릭을 가로채지 않습니다. 대화 집중 시 숨기고 복귀 시 같은 요소를 표시합니다. [소품 뷰어](../office-objects-v1/index.html)의 마당 분류에서 9종을 개별 확인할 수 있습니다.
