# Portfolio Kirby v2

내장 image_gen으로 기존 네 캐릭터 아틀라스의 도트 밀도와 가는 윤곽을 참고해 생성했다. 둥근 몸통, 몸에 붙인 짧은 팔, 작은 포트폴리오 서류를 사용한다. 원본 키 배경은 청록색이다.

- `walking-atlas.png`: 4열 × 3행. 행은 정면·후면·오른쪽, 열은 중립·왼발·통과·오른발의 네 걸음이다. 왼쪽은 오른쪽 행을 반전한다.
- 원본 프레임을 실제 표시 크기×DPR의 Canvas에 한 번만 최근접 샘플링한다. 기존 테두리의 좁은 영역을 매트에서 측정한 기본 2도트 두께의 안쪽 윤곽으로 대체한다. 화면 배율과 DPR에 따라 기기 픽셀로 환산하며, 머리 상단·양옆·발에 같은 기준을 적용한다. 곡선은 원형 거리 기준으로 처리해 대각선만 더 두껍게 되는 사각 거리의 편향을 줄인다. 소품용 2픽셀 윤곽을 원본 위에 덧씌우지 않는다. 완성 프레임은 표시 해상도별로 캐시한다.
- 기준 격자 96×96, CSS 높이 약 6.48cqw. 800단위 방에서 직원과 같은 0.54단위/픽셀 비율을 유지하며 실제 표시 크기는 기기 픽셀에 맞춘다. 여백은 기준 격자의 4픽셀, 그림 높이는 88픽셀에 해당한다. Canvas와 CSS의 픽셀 크기를 맞춰 브라우저가 재축소하지 않으며, 이동 위치도 기기 픽셀에 정렬한다.
- 직원 사무실 빈 공간 (356, 405) → (418, 405) → (418, 338) → (356, 338)을 순환한다. 가구와 칸막이를 통과하지 않는다.
- 이동 거리에 따라 발 프레임이 진행하고 도착하면 쉰다. 포트폴리오 창·마우스 올림·키보드 포커스·모션 감소에서는 멈춘다. 숨겨진 페이지에서는 RAF를 중단한다.
- 커비는 포트폴리오 UI 진입점이며 Backend Worker가 아니다. 걷기가 API를 실행하지 않는다.
- 정확한 생성 프롬프트: `prompts.json`.
