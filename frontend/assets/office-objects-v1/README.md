# Tomade 독립 오브젝트 v1

현재 앱과 이 폴더의 뷰어는 [소품 v4 아틀라스](../office-objects-v4/README.md)와 [직원 책상 v3](../office-objects-v3/README.md)를 사용합니다. 아래 생성 기록과 이 폴더의 PNG는 v1 제작 이력입니다. `prompts.json`의 `file`·`frame`·`width`·`height`는 현재 뷰어의 원본 경로·아틀라스 영역·게임 크기입니다.

현재 뷰어에는 실내 22개 ID와 [마당 아틀라스 9종](../office-courtyard-v2/README.md)을 합쳐 31개 항목을 표시합니다. 두 직원 책상 ID는 같은 승인된 원본을 사용합니다. 마당 분류에서 실내와 같은 픽셀 배율로 비교할 수 있고, 배경 뷰어의 8종을 포함하면 전체 39개 ID입니다.

2026-09-15, 승인된 [두 방 배경](../research-office.png)을 참조해 built-in `image_gen`으로 v1 가구와 소품을 개별 생성했습니다. 현재 앱의 `office-room.ts`는 이후 버전의 에셋을 독립 오브젝트로 배치합니다.

## 확인

Vite가 실행 중이면 http://127.0.0.1:5173/assets/office-objects-v1/index.html 에서 확인할 수 있습니다. 분류별 보기, 밝은/어두운 배경 전환, 개별 오브젝트 1–5배 확대를 지원합니다.

`preview.png`는 뷰어의 업무 가구 화면을 캡처한 검토용 이미지이며 스프라이트가 아닙니다.

## 구성

| 분류 | 에셋 |
| --- | --- |
| 업무 가구 | 직원 책상, 부장 책상, 파란 직원 의자, 초록 직원 의자, 부장 의자, 빈 명패 |
| 모니터 | 비즈니스 막대 차트, 매크로/섹터 추세선, 이벤트/카탈리스트 일정, 부장 모니터 뒷면 |
| 집 소품 | 체크 커튼 창문, 녹색 난로, 청록색 소파, 베이지 러그, 공구 걸이, 책 선반, 수납장, 토마토 심볼, 화분, 풍경 액자, 머그 |

직원 책상은 세 자리에 재사용할 수 있습니다. 기존 캐릭터/걷기 에셋과 바닥/벽 배경은 이번 생성 대상에서 제외했습니다. 선반과 그 위의 작은 책·머그, 공구 걸이와 공구는 각각 한 소품으로 묶었습니다.

## 원본과 표시 방식

- 총 21개 PNG는 각각 하나의 오브젝트만 담은 생성 원본입니다. 알파 채널이 없는 RGB 이미지이며 자홍색을 투명 배경용 색상으로 사용합니다.
- 처음 요청한 투명 출력은 체크무늬가 이미지에 포함되어 나왔으므로 채택하지 않았습니다. 최종 에셋은 단색 자홍색으로 다시 생성했습니다.
- 현재 뷰어와 앱은 `pixel-style.ts`에서 기본 직원 캐릭터와 같은 0.54게임단위/픽셀 배율과 안쪽 2픽셀 검정 윤곽을 적용합니다. `preserveColors: true`로 내부 원본 RGB를 보존하고, 작은 풀·들꽃은 추가 윤곽을 제외합니다. 화면 크기와 무관한 도트 수를 유지하고 최근접 보간으로 표시합니다. 원본 PNG 자체는 변경하지 않습니다. 자세한 제작·표시 기준은 v4 README를 참고하세요.
- 각 모니터는 화면까지 포함한 단일 소품입니다. 현재 내용은 역할을 구분하는 정적 그림이며 실시간 데이터는 아닙니다.
- 명패 원본은 비어 있습니다. 앱에서는 이름을 HTML로 겹치고 그림과 같은 크기의 버튼으로 만들어 부장 대화·직원 조사 노트를 엽니다.
- `office-room.ts`가 배치·깊이·명패 클릭을 담당하며, `OFFICE_SEATS`를 `office-scene.ts`와 공유해 책상·의자와 캐릭터의 착석 위치를 맞춥니다. 걷기·보고는 기존 캐릭터 경로와 프레임을 사용합니다. 별도의 물리 충돌 엔진은 없습니다.

## 생성 기록

공통 프롬프트와 각 오브젝트별 요구사항은 [prompts.json](prompts.json)에 있습니다. 각 `*.source.json`에는 채택한 원본 생성 경로가 보존되어 있습니다. 모든 그림은 built-in `image_gen`을 사용했고 CLI/API fallback은 사용하지 않았습니다.
