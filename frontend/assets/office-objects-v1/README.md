# Tomade 독립 오브젝트 v1

2026-09-15, 현재 [두 방 배경](../research-office.png)을 참조해 built-in `image_gen`으로 가구와 소품을 개별 생성했습니다. 현재 앱의 배경 교체나 배치 구조 변경은 포함하지 않습니다.

## 확인

Vite가 실행 중이면 http://127.0.0.1:5173/assets/office-objects-v1/index.html 에서 확인할 수 있습니다. 분류별 보기, 밝은/어두운 배경 전환, 개별 오브젝트 1–5배 확대를 지원합니다.

`preview.png`는 뷰어의 업무 가구 화면을 캡처한 검토용 이미지이며 스프라이트가 아닙니다.

## 구성

| 분류 | 에셋 |
| --- | --- |
| 업무 가구 | 직원 책상, 부장 책상, 파란 직원 의자, 초록 직원 의자, 부장 의자, 빈 명패 |
| 모니터 | 비즈니스 막대 차트, 매크로/섹터 추세선, 이벤트/카탈리스트 일정, 부장 모니터 뒷면 |
| 집 소품 | 체크 커튼 창문, 녹색 난로, 청록색 소파, 베이지 러그, 공구 걸이, 책 선반, 수납장, 토마토 심볼, 화분, 풍경 액자, 머그 |

직원 책상은 세 자리에 재사용할 수 있습니다. 기존 캐릭터/걷기 에셋과 바닥/벽 배경은 이번 생성 대상에서 제외했습니다. 선반과 그 위의 작은 책·머그, 공구 걸이와 공구는 각각 한 소품으로 묶었습니다.

## 원본과 표시 방식

- 총 21개 PNG는 각각 하나의 오브젝트만 담은 생성 원본입니다. 알파 채널이 없는 RGB 이미지이며 자홍색을 투명 배경용 색상으로 사용합니다.
- 처음 요청한 투명 출력은 체크무늬가 이미지에 포함되어 나왔으므로 채택하지 않았습니다. 최종 에셋은 단색 자홍색으로 다시 생성했습니다.
- `index.html`은 원본을 수정하지 않고 로딩 시 Canvas에서 자홍색과 가장자리의 자홍색 잔상을 제거합니다. 투명 픽셀 경계로 표시 범위를 잡고, `prompts.json`의 `width`를 기준으로 보간 없이 도트로 표시합니다. 이 너비는 검토용 크기이며 실제 사무실 배치 좌표나 충돌 영역을 뜻하지 않습니다.
- 각 모니터는 화면까지 포함한 단일 소품입니다. 현재 내용은 역할을 구분하는 정적 그림이며 실시간 데이터는 아닙니다.
- 명패는 비워 두었습니다. 이름과 클릭 영역은 실제 UI 요소로 별도 배치할 수 있습니다.
- 화면에 보이는 가구의 배치·깊이·착석·클릭 영역을 이 에셋에 연결하는 작업은 아직 하지 않았습니다.

## 생성 기록

공통 프롬프트와 각 오브젝트별 요구사항은 [prompts.json](prompts.json)에 있습니다. 각 `*.source.json`에는 채택한 원본 생성 경로가 보존되어 있습니다. 모든 그림은 built-in `image_gen`을 사용했고 CLI/API fallback은 사용하지 않았습니다.
