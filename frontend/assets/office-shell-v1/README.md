# House shell

현재 입구는 `entrance-v2.png`를 사용합니다. 사용자 첨부 입구를 기준으로 built-in image_gen에서 연결된 가로 목재·ㄱ자 끝단·낮은 문턱·두 단 계단을 재제작했습니다. [생성 기록](entrance-v2.prompt.json).

`office-architecture.ts`의 `createFrontSection`이 직원실과 부장실 하단부를 각각 조립합니다. 직원실은 입구를 포함한 438×44, 부장실은 직선 목재·기단의 282×32 오브젝트입니다. 각 구간은 기둥 안쪽 면에 맞춰 끝나며, 절단 윤곽이 겹치지 않도록 끝의 1단위만 기둥 뒤로 넣습니다. 기둥과 돌 받침은 별도 오브젝트입니다. 집 전체 배경은 여전히 개별 바닥·벽·가구·인물로 구성됩니다.

`concept.png`, `shell-atlas.png`, `prompts.json`은 최초 시안과 6종 구조 에셋 생성 기록입니다. 현재 기둥·처마·돌 받침·통로 목재에는 해당 아틀라스를 계속 사용합니다. 이전의 개별 입구 끝단·문턱·계단 및 전면 기단 배치는 사용하지 않습니다.

바닥은 직원 공간 436×302의 9×6 짜임 블록, 부장 공간 280×268의 6×6 체크로 맞춰 그립니다. 전체 42개 에셋 ID, 101개 배치입니다. [환경 뷰어](../office-environment-v1/index.html).

프레임 색은 입구 목재 면의 평균 RGB를 기준으로 가로 프레임·외곽 기둥·칸막이·벽 하단 목재에 맞춥니다. 원본 결·명암은 유지하고 벽 페인트와 검정 윤곽은 제외합니다. 전면의 인위적 아틀라스 접합점은 양옆의 재질 색을 연결해 검은 홈과 세로 색차를 제거합니다. 처마도 한 스트립으로 구성해 중복 테두리를 없앱니다. 실제 돌 블록과 지붕 타일 자체의 줄눈은 유지합니다.

세 기둥의 받침은 y448–470에 배치하고 목재 끝(y450)을 윗면에 2단위 겹칩니다. 기둥을 받침보다 앞에 그려 검은 외곽선 두 겹이 쌓이지 않게 하며, 지면에 닿는 기둥의 하단 장식 턱은 1.6단위로 줄입니다. 상단 칸막이의 장식 턱은 유지합니다.

집 전체 하단 그림자는 기단과 돌출 계단 형태를 따른 독립 레이어입니다. 기존 발밑 접촉 그림자보다 넓고 옅게 표시하며 대화 집중 모드에서는 마당과 함께 숨깁니다. 물뿌리개는 화단과 같은 이미지 안에 있으므로 물뿌리개 몸통 아래 위치에만 두 겹의 작은 접촉 그림자를 배치합니다.
