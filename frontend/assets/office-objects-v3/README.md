# 직원 책상 스타일 기준

`worker-desk-trial.png`는 새 마당 아틀라스의 벤치 질감을 기준으로 built-in `image_gen`에서 제작했습니다. 프롬프트와 생성 원본 경로는 [prompts.json](prompts.json)에 기록했습니다.

처음에는 패트(`business`) 책상 한 개로 비교했고, 승인 후 패트·매트·게왹이의 세 책상에 같은 원본을 적용했습니다. 138×72 게임 크기·위치·서랍 배치와 공유 좌석 좌표는 유지합니다. 기존 `trialDesk`·`workerDesk` ID도 유지하며 같은 파일을 가리킵니다. 부장 책상과 나머지 소품은 이 책상과 마당의 질감을 기준으로 만든 [v4 아틀라스](../office-objects-v4/README.md)를 사용합니다.

공통 45색으로 강제 변환할 때 생기던 나무결의 색 얼룩을 피하기 위해 도입한 `preserveColors`를 현재는 앱과 뷰어의 모든 소품에 적용합니다. 원본 RGB를 보존하면서 0.54게임단위 도트 격자와 실루엣 안쪽 2픽셀 윤곽을 공유합니다. [소품 뷰어](../office-objects-v1/index.html)에서 원본 질감과 경계를 확인할 수 있습니다.
