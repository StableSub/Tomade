# Tomade 소품 v2 — 캐릭터 기준 픽셀 모델

2026-09-15. 사용자가 기준으로 지정한 녹색 타일 난로에 맞춰 가구·소품 20종을 built-in `image_gen`으로 다시 만들었습니다. 기준 난로는 v1 원본을 복사해 함께 사용합니다. v1 파일은 제작 이력으로 보존합니다. 이후 사용자 피드백에 따라 현재 표시 기준은 난로에서 **기본 직원 캐릭터의 픽셀 배율과 검은 윤곽선**으로 변경했습니다. 이번 변경은 생성 PNG 재제작이 아니라 픽셀 모델의 샘플링·실루엣·윤곽 처리 변경입니다.

## 현재 표시 방식

- 기준은 패트·매트의 128×160 Canvas입니다. 800단위 방에서 160행을 86.4단위로 표시하므로 소품도 **1픽셀 = 0.54 게임 단위**로 샘플링합니다. 직원 책상은 약 256×133, 의자는 74×96픽셀입니다. 이전의 1게임단위 격자가 캐릭터와 동일하다는 설명은 정정합니다. 부장·외계인은 기존에 서로 다른 크기로 표시하므로 직원 캐릭터를 공통 기준으로 삼습니다.
- 캐릭터처럼 최근접 샘플링을 사용해 경계의 검정이 밝은 평균색으로 섞이지 않게 합니다. 물체와 투명한 영역이 만나는 경계는 **실루엣 안쪽 2픽셀을 `#191716`으로 채웁니다.** 대각선 이웃까지 검사해 계단형 모서리를 닫고, 책상 다리 사이·의자 등받이·컵 손잡이의 구멍에도 같은 규칙을 적용합니다.
- 윤곽 처리는 원래의 이진 알파 안쪽만 바꿉니다. 물체 크기를 밖으로 늘리거나 구멍을 메우지 않습니다. 명패·목재 테두리·칸막이는 가장자리를 유지하며 가운데를 늘린 후 최종 경계를 다시 닫습니다.
- 공통 48색 중 바닥 전용 세 색을 제외한 45색으로 소품을 표시합니다. 가장 어두운 색은 캐릭터와 비슷한 짙은 검정으로 바꿨습니다. 나무 바닥 SVG와 반복 타일은 기존 1단위 격자를 유지하며, 바닥·벽면에는 새 검은 윤곽을 추가하지 않습니다.
- 화면 크기·Retina 여부에 따라 소품 자체의 도트 수가 바뀌지 않습니다. 표시 시 최근접 보간을 사용하고 뷰어의 개별 확대는 실제 모델 픽셀의 정수 배율로 표시합니다.
- 원본 PNG에는 생성 모델의 미세한 색 변화가 남을 수 있습니다. 실제 UI와 뷰어는 같은 격자·팔레트 변환을 적용한 결과를 표시합니다. 소스 PNG와 실제 표시용 픽셀은 구분합니다.
- 캐릭터의 걷기·착석·보고 시트와 부장실 모니터 위치는 유지합니다.

## 확인 및 생성 기록

[에셋 뷰어](../office-objects-v1/index.html)는 v2를 로딩하며 모든 소품을 같은 배율로 비교합니다. 개별 확대는 고정 도트 격자를 정수 배율로 보여줍니다. 각 소품의 원본 경로·요청한 크기·최종 프롬프트는 [prompts.json](prompts.json)에 있습니다. CLI/API fallback은 사용하지 않았습니다.

벽과 입구 계단도 단순한 색면으로 다시 만들었으며 [배경 생성 기록](../office-environment-v2/prompts.json)에 보존했습니다. 나머지 배경 모듈은 기존 그림을 같은 격자와 팔레트로 표시합니다.

`frontend/tests/office-ui.mjs`에서 실제 직원 캐릭터와의 픽셀 배율, 실루엣 경계의 검정 연결, 원본 투영 대비 알파·구멍 보존, 공통 팔레트·이진 투명도, 나무 바닥 이음새, 명패 클릭·착석·보고·미니맵을 검증합니다. 그림의 세부 묘사 수준은 전체 소품 비교 화면과 실제 착석 화면에서 별도로 육안 확인합니다.
