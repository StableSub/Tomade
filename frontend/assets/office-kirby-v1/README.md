# Portfolio Kirby

내장 image_gen 도구로 기존 캐릭터 아틀라스의 픽셀 스타일을 참고해 생성한 서류를 든 커비 정면 에셋이다. 원본은 수정하지 않고 청록색 키 배경을 `portfolio-character.ts`에서 제거한다. 분홍색이 지워지지 않도록 기존 자홍색 키 로더와 분리했다.

- 위치: 직원 사무실 오른쪽 아래 빈 칸, 게임 좌표 (356, 405).
- 화면 역할: 클릭하면 기존 포트폴리오 패널을 연다. 연구 Worker는 추가하지 않는다.
- 렌더링: 기존 직원의 0.54 게임단위 픽셀 격자와 안쪽 2픽셀 윤곽, 원본 RGB를 유지한다.
- 자세: 서류를 들고 서 있는 단일 정면. 기존 네 캐릭터의 걷기 시트는 유지한다.
- 프롬프트: `prompts.json`.
