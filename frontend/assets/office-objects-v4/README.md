# 사무실 소품 v4 — 승인된 책상 스타일 전체 적용

2026-09-16. 승인된 [직원 책상](../office-objects-v3/worker-desk-trial.png)과 [마당](../office-courtyard-v2/garden-atlas.png)의 촘촘한 픽셀 질감을 기준으로 built-in `image_gen`에서 26종을 다시 만들었습니다. CLI fallback은 사용하지 않았습니다.

- `furniture-atlas.png`: 부장 책상, 직원 의자 2종, 부장 의자, 소파, 수납장, 창문, 난로, 러그.
- `details-atlas.png`: 모니터 4종, 명패, 책 선반, 공구 걸이, 액자, 작은 화분.
- `structure-atlas.png`: 토마토, 컵, 가로·세로 목재, 칸막이, 기둥, 계단, 벽면.

직원 책상 세 개는 승인된 v3 원본을 함께 사용합니다. 마당은 승인된 v2 원본을 유지합니다. 정확한 나무 바닥 타일의 배치·이음선은 유지합니다.

## 표시 규칙

실내·마당 소품 모두 원본 RGB를 보존합니다. 이전 45색 강제 변환을 사용하지 않으므로 나무결·천·금속의 명암을 다른 색으로 치환하지 않습니다. 기본 직원 캐릭터 기준 0.54 게임단위 격자와 최근접 샘플링을 유지합니다.

물체의 투명한 경계 안쪽 2픽셀에 `#191716` 윤곽을 적용합니다. 대각 모서리에도 같은 두께를 적용하며 외부 크기를 늘리거나 의자·책상·손잡이 틈을 메우지 않습니다. 벽·바닥과 아주 작은 풀꽃에는 별도 검정 윤곽을 넣지 않습니다. 명패·목재 테두리는 가장자리 굵기를 유지하면서 중앙을 늘립니다.

`frames.json`은 원본 아틀라스의 정규화 영역입니다. 부장 책상·의자와 난로 굴뚝 등 셀 경계를 넘은 그림은 각 물체의 전체 모습만 읽도록 영역을 따로 조정했습니다. 벽면은 바깥 여백과 테두리를 제외한 내부 직사각형을 사용합니다. 파일을 잘라 다시 저장하지 않으며 `loadSpriteSource`가 메모리에서 원본 픽셀을 분리합니다.
