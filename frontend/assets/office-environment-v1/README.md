# Tomade 배경 오브젝트 v1

현재 벽·계단은 [v2 보완 에셋](../office-environment-v2/README.md)을 로딩하며 나머지 모듈과 나무 바닥 SVG는 이 폴더의 원본을 유지합니다. 배치 모듈은 소품과 같은 캐릭터 기준 배율과 짙은 윤곽으로 표시하며 벽·바닥은 윤곽을 제외합니다. 반복 바닥 타일의 기존 격자는 유지합니다.

2026-09-15. 현재 [사무실 배경](../research-office.png)의 바닥·벽·출입구를 8종의 독립 에셋으로 구성했습니다. 최초 시안은 built-in `image_gen`으로 만들었고, 현재 나무 바닥은 정확한 정수 좌표로 작성한 `floor-parquet.svg`를 사용합니다. [가구 에셋 21종](../office-objects-v1/README.md)에 이어 배경 자체를 구성하는 부품입니다.

## 보기

Vite 실행 중 http://127.0.0.1:5173/assets/office-environment-v1/index.html 에서 확인합니다. 위쪽 두 방은 이 폴더의 8개 에셋을 26개 위치에 배치해 구성한 검토 화면입니다. 원래 사무실 PNG를 배경에 넣지 않습니다. 바닥, 벽·칸막이, 테두리·출입구를 각각 숨길 수 있으며 아래 에셋을 클릭하면 확대됩니다. 바닥 확대는 타일을 2×2로 반복해 이음새를 확인합니다.

## 표시와 범위

- 바닥과 벽면은 캔버스 전체를 채우는 불투명 텍스처입니다. 목재·칸막이·계단 5종은 자홍색 배경의 RGB 생성 원본이며, 뷰어에서 해당 색을 투명 처리합니다.
- 나무 타일은 96×96 안에 48픽셀 블록 네 개와 16픽셀 판자 세 개씩을 배치합니다. 단색 세 가지와 정수 좌표만 사용하며 모든 이음선은 1픽셀입니다. 위·왼쪽 경계만 그리므로 반복할 때 선이 이중으로 겹치지 않습니다. 방·문턱·통로의 나무 바닥은 같은 패턴 원점을 사용합니다.
- 나무 바닥은 원본 크기도 96픽셀이므로 축소 없이 반복하며 확대 창에서도 정수 배율을 유지합니다. 벽·기둥·테두리·계단은 `pixel-style.ts`에서 게임 좌표 기준의 고정 도트 수와 48색으로 정규화한 뒤 표시합니다. 목재 테두리와 칸막이는 가장자리 크기를 유지하고 가운데만 늘립니다. 방 조립 화면은 충분한 공간에서 800×500, 작은 화면에서는 가용 폭에 맞춥니다.
- 실제 앱도 `office-room.ts`에서 800×500 좌표계로 같은 배경 에셋을 배치합니다. 가구 21종을 더해 총 54개 오브젝트로 구성하며, 기존 캐릭터의 문 통과 경로와 공유 좌석 좌표에 맞춰 배치했습니다. 사무실 전체와 미니맵은 같은 오브젝트 DOM을 사용합니다.
- `preview.png`는 조립한 배경을 브라우저에서 캡처한 검토용 이미지이며, 앱에 쓰이는 배경 파일이 아닙니다.
- 이 배경 전용 미리보기에는 토마토 심볼·가구·창문·캐릭터를 포함하지 않습니다. 실제 사무실에는 앞서 만든 별도 에셋을 함께 배치합니다.

## 생성 기록

최초 이미지 생성 프롬프트는 [prompts.json](prompts.json)에, 생성 원본 경로는 각 `*.source.json`에 있습니다. 현재 나무 타일은 생성 이미지를 편집한 결과가 아닌 코드 기반 SVG 에셋입니다. `prompts.json`의 `file` 항목이 실제 로딩 파일을 지정하며, 나머지 에셋은 기존 생성 PNG를 사용합니다.

기존 `floor-parquet.png`와 `floor-parquet.source.json`은 제작 이력용이며 현재 뷰어에서 사용하지 않습니다. 생성 PNG의 선 좌표 불균일을 축소 필터로 완화하려던 이전 수정은 정렬을 해결하지 못하고 흐림을 만들었으므로 제거했습니다. 현재 SVG의 3×3 반복을 대상으로 48/16픽셀 간격과 경계 1픽셀 조건을 검사하고 브라우저 확대 화면에서 확인했습니다.

## 정돈된 집 외곽 적용

현재 뷰어의 목재·칸막이·계단은 `../office-shell-v1/shell-atlas.png`를 사용합니다. 사각 기둥 캡을 제거하고 돌 기단·처마·문턱을 더해 총 12종 환경 모듈을 표시합니다. 바닥 두 종과 뒤쪽 벽면은 유지하며, 전면 벽지는 표시하지 않습니다.

바닥 정돈: 나무 짜임은 동일한 48/16픽셀 격자를 유지하고 색차와 이음선 대비를 낮췄습니다. 부장실 체크는 생성 PNG 대신 정확한 96×96 SVG를 사용해 두 색면과 경계에 중간색·노이즈가 없습니다. 기둥 돌 받침과 통로 목재 마감도 현재 뷰어에 포함됩니다.

현재 조립 미리보기는 앱과 `office-architecture.ts`를 공유합니다. 독립 타일 카드의 SVG는 패턴 견본이며, 실제 방에는 9×6 나무 블록과 6×6 체크를 내부 치수에 맞춰 그려 가장자리의 얇은 조각을 방지합니다. 기둥 안쪽 테두리·하단 턱과 입구 끝단을 포함해 현재 13개 모듈을 제공합니다.

현재 입구는 `entrance-v2.png`의 연결된 목재·문턱·계단을 사용합니다. 이전의 별도 기단·끝단·문턱·계단 카드는 제외하고 전면 마감 카드로 통합해 현재 10개 환경 모듈을 제공합니다. 상세 생성 기록은 `office-shell-v1/entrance-v2.prompt.json`에 있습니다.
