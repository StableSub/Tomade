# Tomade 배경 오브젝트 v1

2026-09-15. 현재 [사무실 배경](../research-office.png)의 바닥·벽·출입구를 built-in `image_gen`으로 8종의 독립 이미지로 다시 만들었습니다. [가구 에셋 21종](../office-objects-v1/README.md)에 이어 배경 자체를 구성하는 부품입니다.

## 보기

Vite 실행 중 http://127.0.0.1:5173/assets/office-environment-v1/index.html 에서 확인합니다. 위쪽 두 방은 이 폴더의 8개 에셋을 26개 위치에 배치해 구성한 검토 화면입니다. 원래 사무실 PNG를 배경에 넣지 않습니다. 바닥, 벽·칸막이, 테두리·출입구를 각각 숨길 수 있으며 아래 에셋을 클릭하면 확대됩니다. 바닥 확대는 타일을 2×2로 반복해 이음새를 확인합니다.

| 파일 | 용도 |
| --- | --- |
| `floor-parquet.png` | 직원 사무실의 밝은 나무 짜임 바닥, 반복 배치 |

## 표시와 범위

- 바닥과 벽면은 캔버스 전체를 채우는 불투명 텍스처입니다. 다른 5종은 자홍색 배경의 RGB 생성 원본이며, 뷰어에서 해당 색을 투명 처리합니다.
- 뷰어는 원본을 수정하지 않고 `prompts.json`의 논리적 폭에 맞춰 보간 없이 표시합니다. 반복 바닥은 같은 이미지를 Canvas 패턴으로 채웁니다. 벽·테두리는 배치 영역에 맞춰 표시합니다.
- 800×500 조립 좌표는 검토용입니다. 실서비스 화면의 캐릭터 이동·착석·충돌·클릭 영역과 아직 연결하지 않았습니다. 기존 앱 배경은 그대로입니다.
- `preview.png`는 조립한 배경을 브라우저에서 캡처한 검토용 이미지이며, 앱에 쓰이는 배경 파일이 아닙니다.
- 토마토 심볼·가구·창문·소품과 캐릭터는 앞서 만든 별도 에셋을 재사용하는 대상으로, 이번 배경 조립 화면에는 포함하지 않았습니다.

## 생성 기록

공통 프롬프트와 모듈별 지시는 [prompts.json](prompts.json)에, 채택한 생성 원본 경로는 각 `*.source.json`에 있습니다. 모든 이미지는 built-in `image_gen`으로 생성했으며 CLI/API fallback은 사용하지 않았습니다.

나무 바닥은 축소 표시에서 일부 이음선이 사라져 선을 굵고 연속적으로 만드는 보정을 한 번 거쳤습니다. 보정 프롬프트와 이전 원본 경로는 `floor-parquet.source.json`에 보존했습니다.
