# Tomade 마당 소품 v1 (이전 시안)

현재 앱은 [마당 v2](../office-courtyard-v2/README.md)를 사용합니다. 아래 SVG와 배치 설명은 이전 구현 기록입니다.

승인된 세이지색 마당·돌길·토마토 화분 시안을 독립 오브젝트로 구현했습니다. 시안 이미지를 배경으로 붙이지 않고, 기존 소품 색상으로 정수 좌표 SVG를 작성했습니다.

| 파일 | 기본 게임 크기 | 용도 |
| --- | --- | --- |
| tomato-planter.svg | 38×50 | 입구 양옆 화분 2개 |
| stepping-stone.svg | 62×20 | 입구 중심에 이어지는 돌 5개 |
| shrub.svg | 46×38 | 아래쪽 모서리 관목 3개, 크기 변화 |

실제 앱과 [소품 뷰어](../office-objects-v1/index.html)의 마당 탭은 같은 `pixel-style.ts`를 사용합니다. 직원 캐릭터 기준 0.54 게임단위 격자, 기존 팔레트, 실루엣 안쪽 2픽셀 검은 윤곽, 최근접 보간을 적용합니다. 원본 SVG에는 블러·그라데이션·생성형 질감이 없습니다.

`OfficeRoom`이 기존 800×500 실내 좌표 아래로 소품을 배치합니다. 사무실 맞춤 영역은 800×625로 늘려 모바일·가로 창에서도 마당이 잘리지 않게 합니다. 마당과 테라스는 단색이며 접지 그림자는 별도 요소입니다. 대화 집중 모드에서는 바깥 소품을 숨기고 기존 실내 미니맵만 보여주며, 복귀할 때 같은 DOM을 다시 표시합니다.
